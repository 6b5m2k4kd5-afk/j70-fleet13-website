## 🔧 How to Update Content

### Adding a Race Result (5 minutes)
1. Open `fleets/Fleet13/races.md`
2. Edit race table with results
3. Save file
4. Push to GitHub
5. Auto-published in 2 minutes!

### Adding Fleet News (5 minutes)
1. Open `fleets/Fleet13/news.md`
2. Add news entry
3. Save and push
4. Published!

### Changing Fleet Information (2 minutes)
1. Edit `fleets/Fleet13/config.yml`
2. Update name, email, phone, colors
3. Changes apply site-wide

### Adding Photos (10 minutes)
1. Provide photos via Google Drive
2. I'll integrate into gallery
3. Site auto-optimizes images
4. Published on next push
